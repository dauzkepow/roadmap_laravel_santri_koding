#2. JSX = eksetensi sintaks javascript yang memungkinkan kita menulis
kode html di dalam javascript
JSX bukan string atau template engine, melainkan sebuah sintaks khusus
yang akan dikompilasi menjadi fungsi Javascript

Contoh JSX :
const element = <h1>Hello, React!</h1>;

setelah dikompilasi menjadi :
const element = React.createElement("h1", null, "Hello, React!");

Kenapa harus menggunakan JSX :

1. Mudah dibaca, menulis struktur html di javascript
2. Deklaratif, fokus pada UI bukan pada proses manual elemen DOM
3. Integrasi dengan Javascript, bisa menuliskan ekspresi javascript
   langsung di dalam JSX

Aturan Dasar JSX :

1. Hanya boleh ada satu elemen induk (parent element)
// ❌ Salah
return (
  <h1>Hello</h1>
  <p>World</p>
);

// ✅ Benar
return (

  <div>
    <h1>Hello</h1>
    <p>World</p>
  </div>
);

atau bisa menggunakan Fragment <> ... </>

2. Gunakan className bukan class karena class adalah keyword JavaScript
maka di JSX kita gunakan className
<h1 className="title">Hello React</h1>

3. Gunakan camelCase untuk atribut misalnya onclick menjadi onClick,
   tabIndex
   <button onClick={() => alert("Clicked!")}>Klik Saya</button>

#4. Props = cara untuk mengirim data dari parent component ke child
component di React. bersifat read-only data yang dikirim tidak boleh
diubah langsung oleh child component
props = paket yang dikirim dari orang tua (parent) ke anak (child)
anak hanya bisa menerima paket tersebut dan tidak mengubah isi paket
Konsep = function dengan (parameter)

Props bersifat read-only:
function Welcome({ name }) {
// ❌ Salah: props tidak boleh diubah
// name = "Orang Lain";

return <h1>Halo, {name}!</h1>;
}

#9. Form (Controlled vs Uncontrolled) = elemen html <input>, <textarea> dan
<select> yang digunakan untuk menerima input dari pengguna
login, register, input data

cara utama untuk mengelola form :
- Controlled Component = nilai input dikendalikan oleh state di React
- Uncontrolled Component = nilai input langsung diambil dari DOM dengan ref

Perbedaan :
-Controlled Component-
Nilai input dikendalikan React melalui state.
Lebih mudah dikontrol dan divalidasi.
Cocok untuk form kompleks.
lebih sering digunakan

-Uncontrolled Component-
Nilai input langsung diambil dari DOM.
Lebih sederhana, tapi kurang fleksibel.
Cocok untuk form sederhana atau sekali pakai.

#10. useEffect = hook bawaan react yang digunakan untuk menjalankan kode ketika:
- component pertama kalo dirender (mount)
- component diperbarui (update)
- component dihapus (unmount)

contoh kasus useEffect :
- ambil data dari API
- menjalankan event listener
- mengatur timer atau interval
- mengupdate title halaman

hook yang digunakan untuk menangani efek samping di react


sintaks dasar :
useEffect(() => {

  // kode yang dijalankan
  
}, [dependencies]);

fungsi pertama (callback) = kode yang akan dijalankan
array dependencies = menentukan kapan efek dijalankan


#11. useRef = hook react untuk :
- menyimpan nilai yang bisa diubah tanpa memicu re-render
- mengakses elemen DOM secara langsung
- Menyimpan Data Sebelumnya

sintak dasar :
const refContainer = useRef(initialValue); //simpan nilai

refContainer.current // merubah nilai yang bisa diakses tidak memicu re-render


Perbedaan useRef vs useState
useState :
- perubahan nilai memicu re-render
- digunakan untuk data yang mempengaruhi tampilan UI

useRef :
- perubahan nilai tidak memicu re-render
- digunakan untuk menyimpan data sementara atau referensi DOM


#12. Memoization (React.memo, useMemo, useCallback)
=> teknik meningkatkan performa aplikasi dengan mencegah perhitungan ulang
atau re-render yang tidak diperlukan
=> teknik optimasi dimana hasil perhitungan atau render disimpan (cache)
sehingga jika input tidak berubah, react tidak perlu merender ulang

berguna untuk :
- mencegah re-render component yang tidak perlu
- menghemat perhitungan yang berat
- menjaga referensi fungsi tetap sama agar tidak memicu perubahan di
child component

React.memo = mencegah re-render component jika props tidak berubah
useMemo = mencegah perhitungan ulang yang berat dengan menyimpan hasilnya
useCallback = mencegah pembuatan ulang fungsi agar referensinya tetap sama
