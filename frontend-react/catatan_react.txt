1. Instalasi dan Persiapan Frontend React

- Buat project React Vite
pastikan node js sudah terinstalasi
pastikan berada di folder fullstack-javascript

buat project baru dengan nama frontend-react, buka cmd ketik :
npm create vite frontend-react -- --template react
cd frontend-react
npm install
code .

jalankan react :
npm run dev

buka = http://localhost:5173/


- Install Library pendukung
axios = melakukan http request ke dalam rest api
npm install axios

js cookie = manajemen cookie dalam browser untuk token
npm install js-cookie

react router DOM = buat navigasi route
npm install react-router-dom

buka src/main.jsx, ubah kodenya 

- Konfigurasi Endpoint API Backend
agar tidak perlu menuliskan endpoint secara berulang-ulang di semua component
